## 🌟 Vision & Overview

**ENGINEER 2.0** is an interactive, cyberpunk-inspired digital symposium engineered for **Prompt Utsav & National Engineers' Day**. Built to bridge century-old architectural marvels with quantum and AI paradigms, the platform provides an interactive audiovisual space experience honoring the pioneers of the past while equipping the creators of 2035.

---

## 🚀 Key Interactive Modules

### 🏛️ 1. The Heritage Core: Sir M. Visvesvaraya Chronicles
- **Interactive Chronology**: Trace the life and groundbreaking civil feats of Sir MV — from the automated sluice floodgates at Khadakwasla to the architectural wonder of the Krishna Raja Sagara (KRS) Dam.
- **Engineering Philosophy Matrix**: Discover foundational principles that revolutionized Indian infrastructure and water governance.

### 🌌 2. The Multi-Discipline Engineering Universe
- Dynamic spectrum explorer traversing core & frontier engineering domains:
  - 💻 **Software & Computational Intelligence**
  - 🚀 **Aerospace & Deep-Space Exploration**
  - 🤖 **Autonomous Robotics & Cybernetics**
  - 🧬 **Bioengineering & Synthetic Biology**
  - 🏗️ **Smart Civil Megastructures & Sustainable Infra**
  - ⚛️ **Quantum Computing & Nanomaterials**

### 🧠 3. AI × Engineering Fusion Engine
- Deep-dive into how Large Language Models, Neural Architecture Search, and Generative Simulation are transforming traditional engineering lifecycles.
- Dynamic interactive tabs illustrating real-world AI-engineered breakthroughs.

### 🧩 4. The Engineer's Mindset Challenge (Interactive Quiz)
- Live interactive IQ and scenario puzzle simulator with real-time feedback, algorithmic scoring, sound synthesis, and instant analysis of cognitive engineering traits.

### 🔮 5. Horizon 2035: Speculative Tech Radar
- Predictive technology roadmap detailing next-decade evolutions: Dyson sphere prototypes, room-temperature superconductors, neural lace interfaces, and carbon-negative cities.

### 🪪 6. Autonomous Engineer Pass Generator
- Users customize their handle, engineering discipline, and clearance tier to generate an **authenticated Cyber Engineer Credential Pass** with real-time canvas rendering and 1-click high-resolution PNG export.

### 🎟️ 7. Event Operations & Workshop Arena
- Complete symposium schedule, keynote speaker dossiers, hands-on hackathons, technical paper presentation tracks, and real-time registration modal with confetti detonation.

### 🔊 8. Procedural Web Audio Sound Engine
- Zero-external-asset dynamic Web Audio API sound synthesis simulating sci-fi UI clicks, access grant chimes, frequencies, and alert tones with global mute toggles.

## 🛠️ Architecture & Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Dev Server**: [Vite 8](https://vitejs.dev/)
- **Styling**: [TailwindCSS 3.4](https://tailwindcss.com/) with custom Glassmorphism & Blueprint grid shaders
- **Animation Orchestration**: [Framer Motion 13](https://www.framer.com/motion/)
- **Typography**: Space Grotesk (Display), JetBrains Mono (Terminal Data), Inter (Clean UI body)
- **Icons**: [Lucide React](https://lucide.dev/)
- **FX & Particles**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Audio**: Custom Web Audio Synthesizer hook (`useSoundEffects.ts`)
- **CI/CD**: GitHub Actions Automated Pipeline (`.github/workflows/deploy.yml`)

## ⚡ Quickstart Guide

### Prerequisites
- [Node.js](https://nodejs.org/) `>= 18.0.0`
- [npm](https://www.npmjs.com/) `>= 9.0.0`

### 1. Clone the repository
```bash
git clone https://github.com/innocentgaming/PROMTUTSAV-Adityayadav.git
cd PROMTUTSAV-Adityayadav
```

### 2. Install dependencies
```bash
npm install
```

### 3. Launch the development server
```bash
npm run dev
```
Navigate to `http://localhost:5173` to explore the experience live with Hot Module Replacement.

### 4. Build for production
```bash
npm run build
```

### 5. Deploy to GitHub Pages
```bash
npm run deploy
```

---

## 🌐 Deployment Details

This project is configured for automated multi-channel deployment:

1. **GitHub Pages (Automated)**:
   Any push to the `main` branch automatically triggers `.github/workflows/deploy.yml` which builds the client bundle and updates the live site:
   👉 **[https://innocentgaming.github.io/PROMTUTSAV-Adityayadav/](https://innocentgaming.github.io/PROMTUTSAV-Adityayadav/)**

2. **Manual Instant Deploy**:
   Running `npm run deploy` invokes `gh-pages -d dist` to immediately push production builds to the `gh-pages` branch.
